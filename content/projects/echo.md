Echo imports Instagram JSON exports into a local conversation library, preserving source exports while combining history across incremental imports. Its Vue interface supports message search, shared media browsing, and optional, user-initiated ChatGPT analysis.

The installed edition uses a local Node.js server, SQLite, and managed media files. An independent browser viewer stores archives in IndexedDB. Both interfaces use Nyx Kit components and SCSS styling.
